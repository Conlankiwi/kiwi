# Qwen API 调用示例项目

## 项目简介
本项目演示如何通过Python和Node.js调用阿里云百炼平台的Qwen API。

## 文件结构
- `qwen_chat.py` - Python版本对话机器人
- `index.js` - Node.js版本代码生成示例
- `package.json` - Node.js依赖配置
- `.gitignore` - Git忽略文件配置

## 使用方法
1. 配置API Key（在百炼平台获取）
2. 安装依赖：`pip install requests` 和 `npm install`
3. 运行脚本：
   - Python: `python3 qwen_chat.py`
   - Node.js: `node index.js`
